# AI Workplace Hub

Build a modern, responsive web application called AI Workplace Productivity Assistant.

Create one integrated AI productivity dashboard, not separate apps. The platform is for professionals and students who want to automate workplace tasks using AI. Design it as a polished SaaS product with a clean, modern, professional look.

Visual Style

Clean white or very light background

Dark or navy sidebar

Indigo, blue, or purple accent colors

Rounded cards

Subtle shadows

Clear spacing

Modern font such as Inter

Premium, minimal, professional interface

Collapsible left sidebar

App title

Main content area with cards, forms, and generated outputs

Desktop, tablet, and mobile support

AI Chatbot Interface

Create a workplace AI chatbot with:

Text input

Suggested prompt chips:

Prompt Engineering

For every AI feature, use structured prompts containing:

Role

Context

Objective

Constraints

Output format

Keep the prompt logic clear, consistent, and workplace-focused.

Editable Outputs

All AI-generated content must be editable before copying or saving.

UX States

Include:

Loading states

Empty states

Error states

Success states

Responsive Design

The app must work properly on mobile and desktop.

Sidebar collapses into a drawer on mobile

Cards stack vertically on small screens

Text areas remain readable and usable

Responsible AI Disclaimer

Add a visible disclaimer that says:

AI may make mistakes. Users should review all outputs before using them. Do not enter confidential, sensitive, or personal information unless allowed.

Overall Goal

Make the app feel like a real enterprise productivity platform with professional UI/UX, practical AI use, and a polished dashboard experience.

Build this as one unified platform with all features inside a single dashboard. Focus on usability, clarity, and modern design.
